# Shattered Realms Asset Manifest

## Required asset classes per faction
### Creatures (14 each)
For every base and upgrade:
- battle animation/model source
- battle animation export
- adventure-map animation where creature may appear on map
- large recruitment icon
- small icon
- ability VFX
- sound set or approved reusable base sound where licensing permits

### Heroes
- portrait large/small
- adventure-map hero representation as required by VCMI class setup
- battle hero animation references
- biography / specialization text

### Town
- full town background
- per-building visual layers
- building icons
- hall layout art
- fort/citadel/castle progression
- siege screen / battlefield presentation
- faction iconography
- puzzle/Grail presentation where required
- adventure-map town object animation

### Environment
- terrain tiles / transitions
- roads or environment-compatible transitions where needed
- decorative obstacles
- visitable map objects
- battlefield background/obstacles

## Animation quality gate
Every combat creature must have readable states for idle/fidget, movement, attack, hit, defend and death before its art is considered release-ready. Ranged/caster creatures additionally need projectile/cast presentation. Special abilities require a clear but restrained cue.

## Art-production rule
Source art and generated assets must be stored separately from game-ready exports. No third-party copyrighted asset may be committed without a compatible license/permission and attribution where required.
