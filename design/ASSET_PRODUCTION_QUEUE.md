# Asset Production Queue — Milestone A

This queue converts the Crimson Court art bible into batches that can be generated/painted, reviewed, animated and exported without losing visual consistency.

## A1 — Creature concept sheets
One neutral-pose concept sheet per base/upgrade pair:
1. Veinling / Bloodbound
2. Thorn Dancer / Crimson Dancer
3. Gorewing / Bloodwing
4. Hemomancer / Vein Oracle
5. Scarlet Huntress / Bloodstalker
6. Sanguine Noble / Crimson Archon
7. Blood Phoenix / Eternal Blood Phoenix

Each sheet must include front 3/4, side silhouette, palette/material swatches, weapon/prop detail and explicit upgrade differences.

## A2 — Battle animation masters
For every creature:
- idle master
- fidget
- move
- melee attack or ranged/cast
- hit
- defend
- death
- special ability cue where applicable

## A3 — UI exports
For each creature:
- large recruitment portrait/icon
- small icon
- clean transparent silhouette
- optional ability icon set

## A4 — Heroes
16 portrait masters + 16 small portraits + 16 specialty icons.
Portrait crop must remain readable at classic H3 scale.

## A5 — Town
1. locked town background composition
2. building paintovers/layers
3. clickable area masks/borders
4. hall/guild backgrounds
5. building icons
6. map-town animation
7. puzzle-map master -> 48 pieces

## A6 — Siege
Background, static wall sections, four destructible wall pieces, three towers, battlements, gate/arch, moat/bank, tower icons.

## A7 — Spells
16 × book/scroll/effect/immunity/scenario icon family + VFX masters.

## Review gates
**Concept gate:** silhouette and lore.
**H3 gate:** readable and painterly at target scale.
**Animation gate:** anticipation/impact/death clarity.
**Technical gate:** correct dimensions/transparency/palette/metadata.
**Runtime gate:** no missing-resource errors and correct in-game placement.

## Source policy
Keep editable masters separate from runtime exports. Record prompt/reference provenance for generated assets. Final project ships only assets we have the right to distribute.
