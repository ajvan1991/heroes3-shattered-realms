# Crimson Court Visual Reference Board v0.1

A first coherent concept board has been generated for the Crimson Court production wave.

## What it establishes
- town mood: black gothic/obsidian Blood Elf court under a red moon;
- progression language for village/town/city/capitol and fort/citadel/castle;
- siege family language;
- T1 Veinling -> Bloodbound visual progression;
- T2 Thorn Dancer -> Crimson Dancer visual progression;
- Vaelor and Aveline portrait/body direction;
- banner, puzzle-map, UI and creature-icon visual language.

## Authority
This board is **CONCEPT reference only**. It is not a sprite sheet, not a runtime town background, not a DEF/JSON animation, and not evidence that any manifest resource exists.

The machine-readable art prompts and animation contracts remain the production specification. Individual runtime assets must be recreated/cropped/redrawn at their exact target sizes, checked into the expected resource path, then converted and validated in VCMI.

## Corrections before runtime production
Text labels embedded by image generation are non-authoritative. Creature/hero specialty text, dimensions and UI labels must come from repository data, never from text visible on this board.

The board intentionally explores a stronger gothic silhouette. Final town art must retain the Blood Elf/aristocratic identity and avoid reading as Inferno, demon architecture, or generic undead.
